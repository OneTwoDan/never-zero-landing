# Never Zero: Push-Ups - Landing & Legal

Esta es la página de presentación y el portal de soporte legal para la aplicación móvil **Never Zero: Push-Ups**.

## Propósito
Este repositorio existe principalmente para alojar las páginas públicas obligatorias requeridas por **Google Play Store** y para cumplir con las normativas de privacidad:
- **Política de Privacidad** (`/privacy`)
- **Solicitud de Eliminación de Datos** (`/delete-account`)

## Stack Tecnológico
- **Framework:** Next.js (App Router)
- **Estilos:** Tailwind CSS (Dark theme / Brutalist design)

## Desarrollo Local

Para correr el proyecto en tu máquina:

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## Despliegue
Este sitio es estático/SSR y está optimizado para ser desplegado fácilmente y de forma gratuita en plataformas como **Vercel** o **Netlify**.
